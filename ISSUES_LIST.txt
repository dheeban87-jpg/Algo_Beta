ISSUE-15 TCAS direction-flip → Phase 6 options handoff         📋 SPEC READY

  CORE INSIGHT:
    When TCAS fires (RA or ALIM) on a losing position, it is
    confirming the REAL market direction. The equity trade was
    wrong — the opposite direction is now confirmed by price action.

    LONG + TCAS fires (price falling)  → confirmed BEARISH → PUT
    SHORT + TCAS fires (price rising)  → confirmed BULLISH → CALL

    Example: ICICI entered LONG (gap-down bounce expected). Price
    kept falling, TCAS fired ALIM. Confirmed direction = BEARISH.
    Phase 4 exits equity, hands the signal to Phase 6.
    Phase 6 uses its own entry logic to decide when and how to
    enter a PUT. Phase 4's job ends at the handoff.

  PHASE 6 IS CALL-ONLY:
    Phase 6 only runs Bull Call Spread (BULLISH direction).
    PUT signals are not supported and must be rejected.

    Therefore ISSUE-15 only fires when a SHORT position is stopped:
      SHORT + TCAS fires (price rising) → confirmed BULLISH → CALL ✅
      LONG  + TCAS fires (price falling) → confirmed BEARISH → PUT  ❌ SKIP

  TRIGGER — TCAS RA or ALIM on a LOSING SHORT position only:
    Conditions (ALL must be true):
      1. Equity direction = SHORT
      2. TCAS alert = RA or ALIM
      3. Position is in loss (equity_pnl < 0)
      4. Kalman velocity > +0.3 (price rising — confirmed BULLISH)
      5. Kalman acceleration same sign as velocity (momentum
         still building, not already reversing)
      6. Time < 13:30 (Phase 6 still has time to act)

  CONFIRMED DIRECTION:
    Always BULLISH (only SHORT failures are passed through)
    Phase 6 runs its existing Bull Call Spread logic.

  DATA PACKAGE — TCASDirectionSignal (fire-and-forget to Phase 6):
    symbol              : str
    confirmed_direction : 'BULLISH' | 'BEARISH'
    signal_time         : datetime
    signal_price        : float      (price at TCAS trigger)
    equity_entry        : float      (original equity entry price)
    equity_stop         : float      (original stop — now breached)
    atr                 : float      (ATR for Phase 6 sizing/strikes)
    kalman_velocity     : float      (momentum magnitude)
    kalman_acceleration : float      (momentum still building?)
    tcas_alert          : str        ('RA' or 'ALIM')
    equity_pnl          : float      (negative — confirms direction)

  ARCHITECTURE — CRITICAL CONSTRAINT:
    Phase 4 exit is UNCONDITIONAL. Handoff is fire-and-forget:
      1. TCAS fires → _execute_exit() runs → equity closed
      2. Post TCASDirectionSignal to Phase 6 async queue
      3. Phase 6 handles everything else with its own logic
      4. Phase 4 has ZERO dependency on Phase 6 response
    Phase 4 must NEVER wait for Phase 6 before closing equity.

  FILES TO TOUCH (when implementing):
    phase4_portfolio_manager.py  — in _execute_exit(), after exit
                                   confirmed: if SHORT + TCAS_RA/ALIM
                                   + pnl < 0 + Kalman conditions met

    phase6_options_advisor.py    — add on_tcas_direction_signal(signal)

                                   Call Spread logic (no new strategy
