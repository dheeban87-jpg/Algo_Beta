Component Deep Dive

🔭 Gap Scanner

Runs at 09:15 open tick. Scans the 147-stock universe for qualifying gap moves against prior session close.

  • Gap % = (open − prev_close) / prev_close × 100
  • Filters: min gap threshold (e.g., >0.5%) and max cap (avoids extreme circuit-breaker gaps)
  • Classifies as Gap-Up (short candidate) or Gap-Down (long candidate)
  • Clean gap vs. messy gap distinction — clean gaps with no prior day fill have higher reversion probability

Self-contained 147-stock universe Kite WebSocket

🎯 Signal Scoring Engine

Multi-factor composite score (0–100) that weighs gap quality, volume confirmation, and time urgency.

  • Gap Quality: Size, cleanliness (no partial fills in prior session), Fibonacci alignment
  • Volume Burst: Opening volume ≥ 1.5× avg — institutional participation signal
  • Time Bonus: Earlier entries score higher (09:15–09:20 window > 09:35+)
  • Direction Clarity: Penalizes ambiguous setups with mixed signals
  • Score ≥ 85 → full size; 70–84 → reduced size; <70 → skip

🚀 Execution Layer

Order placement bypasses pykiteconnect SDK — uses raw requests.post() to comply with SEBI April 2026 mandate.

  • Endpoint: POST https://api.kite.trade/orders/{variety}
  • Injects market_protection=-1 as required by NSE/SEBI mandate
  • Auth: api_key + access_token headers
  • Product: MIS (intraday auto square-off)
  • Static IP: Surfshark VPN dedicated IP 23.27.229.173

🛡️ TCAS Stop-Loss Engine

Aviation-inspired Collision Avoidance System. Sets and monitors the hard stop for each Ph5 position.

  • Stop distance: 1.5–2× ATR from entry price
  • ALIM (proximity warning): triggers when price is within 1× ATR of stop and moving toward it
  • Tier 1 fast-check pipeline: 10-second cycle
  • Known gap (P1 fix): ALIM exit not yet wired into Tier 1 — only hard stop triggers. ALIM proximity exit needs to be added to Tier 1 fast-check pipeline
  • Exit uses same raw requests.post() path as entry

1.5–2× ATR stop ALIM proximity Tier 1 10s cycle

🎯 ILS Profit Target

Instrument Landing System — locks in profit when price reaches the reward target.

  • Target: 2–3× ATR from entry (minimum 1:2 R:R)
  • Monitored in Tier 1 alongside TCAS every 10 seconds
  • Can implement partial exits at 1.5× ATR + trail remainder
  • Gap reversion target: prior session close is the natural magnet / ILS beacon

2–3× ATR target Prior close beacon 1:2+ R:R

💾 State Persistence

SQLite-backed position state. Known fragility: broker sync can overwrite custom fields on the position dict.

  • Databases: algo_beta.db (trades) + mission_control.db (state)
  • Known gap (P2 fix): Fields like breakeven_trail_applied, updated stop_price, exit_retries can be lost between monitoring cycles when broker sync overwrites the position dict
  • Fix: explicitly persist custom fields through reconciliation cycle — snapshot-under-lock → mutate-outside → write-under-lock
  • Telegram bot receives all entry/exit/session summary events
